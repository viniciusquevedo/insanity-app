# Insanity para Windows

Instaladores do aplicativo da guild Insanity (Sala de Voz com atalhos que funcionam com o Tibia em foco).

- Baixe o **Insanity-Setup** mais recente em [Releases](https://github.com/viniciusquevedo/insanity-app/releases/latest).
- Na primeira vez o Windows avisa "O Windows protegeu o computador" (o instalador não tem certificado): clique em **Mais informações → Executar assim mesmo**.
- Depois de instalado, o app se atualiza sozinho: quando houver versão nova, aparece uma notificação e o item **Atualizar agora** no ícone do relógio.

O app não mexe no jogo: só abre o site https://insanity.app.br e escuta as teclas de atalho do Windows, como o TeamSpeak.
